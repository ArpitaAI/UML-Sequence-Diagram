# UML Sequence Diagram

## Overview

A UML Sequence Diagram is a behavioral diagram used to show how users, objects, systems, or components interact with each other in a specific order over time.

It represents communication using lifelines, messages, conditions, loops, and alternative flows. Sequence diagrams are useful for understanding how a system behaves before implementation.

## Real-World Applications

Sequence diagrams are commonly used in software development and system design.

Some real-world examples include:

- User login and authentication systems
- ATM withdrawal systems
- Library management systems
- Hospital booking systems
- E-commerce order processing
- Payment systems
- Database interactions
- API communication
- Registration and verification systems

Software engineers, system analysts, developers, and architects use sequence diagrams to understand the interaction between different parts of a system.

## My Work

In this project, I created UML Sequence Diagrams based on several real-world scenarios.

The work includes concepts such as:

- Actors and system participants
- Lifelines
- Activation bars
- Request and response messages
- Database interaction
- Alternative flows using `alt`
- Conditional operations
- Loops
- Verification and validation

The scenarios include:

### ATM Cash Withdrawal
A customer inserts a card, the system verifies the user, and the withdrawal request is either completed or rejected.

### Library Book Borrowing
A student requests a book, and the system checks the student's borrowing status before approving or denying the request.

### Hospital Bed Booking
A patient requests a bed, and the system checks doctor/reference information and facility availability before confirming the booking.

### User Login Verification
A user attempts to log in, and the system verifies the credentials. If verification repeatedly fails, the user may be blocked.
